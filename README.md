# Crimson Web

An interactive portfolio homepage for Crimson, built with React, Three.js, GSAP, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Included

- Persistent responsive Three.js scene
- Scroll-pinned process sequence
- Horizontal desktop work rail with mobile fallback
- Interactive capabilities and automation sections
- Responsive navigation and full-screen mobile menu
- Reduced-motion and reduced-transparency fallbacks
- Image loading and error states
- Client-side form validation and completion states
- Optimized WebP project imagery

## Before deployment

Connect the contact form to the preferred email, CRM, or form endpoint. The current build validates locally and demonstrates the completed interaction states without sending data to an external service.
